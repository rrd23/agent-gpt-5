# Продукт

Погодный агент с автоматическим определением языка - интеллектуальный чат-бот, который предоставляет информацию о погоде на языке пользователя.

## Основные возможности
- Получение текущей погоды для любого города через OpenWeather API
- Автоматическое определение языка пользователя с помощью langdetect
- Ответы на том же языке, на котором задан вопрос
- Интеграция с различными LLM моделями через OpenRouter API
- Поддержка function calling для получения данных о погоде
- Гибкий выбор AI модели через конфигурацию

## Целевая аудитория
Пользователи, которым нужна быстрая и удобная информация о погоде с возможностью общения на родном языке.
