# Структура проекта

## Организация файлов
```
.
├── main.py                 # Основной файл приложения
├── .kiro/                  # Конфигурация Kiro AI
│   └── steering/           # Правила для AI ассистента
├── .vscode/                # Настройки VS Code
│   └── settings.json       # Конфигурация редактора
└── requirements.txt        # Зависимости Python (если создан)
```

## Архитектура кода в main.py

### 1. Настройка API-ключей
- Инициализация OpenAI клиента с OpenRouter endpoint
- Загрузка переменных окружения из .env файла через python-dotenv

### 2. Описание инструментов (tools)
- Определение функции `get_weather` для OpenAI function calling
- Схема параметров для города и языка

### 3. Реализация функций
- `get_weather()` - получение данных о погоде через OpenWeather API
- Обработка ошибок и валидация данных

### 4. Основной цикл
- `chat()` - интерактивный чат с пользователем
- Автоматическое определение языка
- Обработка function calls и генерация ответов
- Дополнительные заголовки для OpenRouter API

## Соглашения по коду
- Используются секции с комментариями для разделения логических блоков
- Обработка исключений для всех внешних API вызовов
- Таймауты для HTTP запросов (5 секунд)
- Возврат структурированных ошибок в формате dict
